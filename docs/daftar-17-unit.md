# Daftar 17 Unit Kompetensi: Web Developer

Skema Sertifikasi: Web Developer. Nomor: 03/02/LSPP1/SKM.03/01/2022.

## Unit 1. Menganalisis tools (J.620100.001.01)

1. Elemen: Mengidentifikasi tools yang akan digunakan
   - 1.1 Mengidentifikasi kebutuhan tools perangkat dari dokumen yang tersedia.
   - 1.2 Mengidentifikasi kemungkinan penggunaan tools yang tersedia.
2. Elemen: Menggunakan tools perangkat lunak
   - 2.1 Memilih tools pengembangan sesuai kebutuhan lingkungan pengembangan.
   - 2.2 Menguji coba penggunaan tools pengembangan yang diperlukan.
   - 2.3 Mengidentifikasi risiko pengembangan sistem dengan menggunakan tools tersebut.

## Unit 2. Menganalisis skalabilitas perangkat lunak (J.620100.002.01)

1. Elemen: Mengumpulkan kebutuhan skalabilitas
   - 1.1 Mengidentifikasi lingkup (scope) sistem teridentifikasi.
   - 1.2 Mengidentifikasi lingkungan operasi aplikasi.
2. Elemen: Menganalisis kebutuhan skalabilitas
   - 2.1 Menganalisis masalah skalabilitas berdasarkan lingkup dan lingkungan operasi sistem.
   - 2.2 Menganalisis kompleksitas aplikasi sesuai dengan kebutuhan pemrosesan dan jumlah data/pengguna yang akan terlibat.
   - 2.3 Menganalisis kebutuhan perangkat keras.
   - 2.4 Mendokumentasikan hasil analisis.

## Unit 3. Melakukan identifikasi library, komponen, atau framework yang diperlukan (J.620100.003.01)

1. Elemen: Menganalisis library, komponen, atau framework yang sesuai dengan konteks
   - 1.1 Mengidentifikasi ruang lingkup kebutuhan akan library, komponen atau framework sesuai lingkungan pengembangan.
   - 1.2 Membandingkan keuntungan penggunaan library, komponen atau framework dibandingkan dengan mengembangkan sendiri.
2. Elemen: Membuat proof of concept library, komponen atau framework berdasarkan konteks kebutuhan
   - 2.1 Membuat fitur-fitur terkait penggunaan library, komponen atau framework versi sederhana.
   - 2.2 Mendemostrasikan manfaat penggunaan.
3. Elemen: Merancang integrasi dan batasan penggunaan library, komponen atau framework
   - 3.1 Menetukan rencana integrasi.
   - 3.2 Mengidentifikasi limitasi.

## Unit 4. Merancang user experience (J.620100.006.01)

1. Elemen: Menganalisis kebutuhan dan skenario penggunaan
   - 1.1 Mengidentifikasi berbagai kebutuhan interaksi sesuai skenario proses aplikasi.
   - 1.2 Mengidentifikasi jumlah maksimal aksi untuk setiap skenario interaksi.
2. Elemen: Merancang layout tampilan dan skenario penggunaan
   - 2.1 Mengidentifikasi jumlah aksi maksimal sebagai batas atas interaksi.
   - 2.2 Merancang layout tampilan yang memfasilitasi batas atas interaksi.
   - 2.3 Mengembangkan skenario lain dengan jumlah aksi dibatasi agar kurang dari batas atas interaksi.

## Unit 5. Mengimplementasikan pemrograman terstruktur (J.620100.017.02)

1. Elemen: Menggunakan tipe data dan control program
   - 1.1 Menggunakan tipe data yang sesuai standar yang ditentukan.
   - 1.2 Menggunakan syntax program yang dikuasai sesuai standar.
   - 1.3 Menguasai struktur kontrol program yang digunakan sesuai standar.
2. Elemen: Membuat program sederhana
   - 2.1 Menulis program input output untuk memasukkan data dari keyboard dan menampilkan ke layar monitor termasuk variasinya sesuai standar masukan/keluaran telah dibuat.
   - 2.2 Menerapkan struktur kontrol percabangan dan pengulangan dalam implementasi program telah digunakan.
3. Elemen: Membuat program menggunakan prosedur dan fungsi
   - 3.1 Menulis program menggunakan prosedur yang dibuat sesuai aturan penulisan program.
   - 3.2 Menulis program menggunakan fungsi yang dibuat sesuai aturan penulisan program.
   - 3.3 Menulis program menggunakan prosedur dan fungsi secara bersamaan yang dibuat sesuai aturan penulisan program.
   - 3.4 Memberikan keterangan untuk setiap prosedur dan fungsi telah dibuat.
4. Elemen: Membuat program menggunakan array
   - 4.1 Menulis program dengan dimensi array telah ditentukan.
   - 4.2 Menulis program dengan tipe data array telah ditentukan.
   - 4.3 Menulis program dengan panjang array telah ditentukan.
   - 4.4 Menulis program dengan pengurutan array telah digunakan.
5. Elemen: Membuat program untuk akses file
   - 5.1 Membuat program untuk menulis data dalam media penyimpan.
   - 5.5 Membuat program untuk membaca data dari media penyimpan.
6. Elemen: Mengompilasi program
   - 6.1 Mengoreksi kesalahan kompilasi kode program.
   - 6.2 Memperbaiki kesalahan syntax dalam program.

## Unit 6. Mengimplementasikan pemrograman berorientasi objek (J.620100.018.02)

1. Elemen: Membuat program berorientasi objek dengan memanfaatkan class

   - 1.2 Membuat properti class yang akan direalisasikan dalam bentuk prosedur/fungsi.

2. Elemen: Menggunakan tipe data dan control program pada metode atau operasi dari suatu kelas

   - 2.2 Menguasai sintaks program sesuai dengan bahasa pemrogramnnya.

   - 3.2 Menerapkan polymorphism pada class.
   - 3.3 Menerapkan overloading pada class.
4. Elemen: Membuat program object oriented dengan interface dan package
   - 4.1 Membuat interface class program.
   - 4.2 Membuat paket dengan program.
5. Elemen: Mengompilasi program
   - 5.1 Mengoreksi kesalahan program.
   - 5.2 Menghasilkan program yang bebas salah sintaks.

## Unit 7. Menggunakan SQL (J.620100.020.02)

4. Elemen: Melakukan operasi relasional

   - 4.2 Menggunakan perintah DML untuk manipulasi antar tabel.
   - 4.3 Menggunakan perintah DML untuk manipulasi antar-view.

5. Elemen: Membuat stored procedure
   - 5.1 Membuat stored procedure dengan perintah SQL.

6. Elemen: Membuat function

7. Elemen: Membuat trigger

   - 7.2 Menguji kesesuaian hasil trigger.
8. Elemen: Melakukan perintah commit dan rollback
   - 8.1 Melakukan perubahan data dengan perintah commit.
   - 8.2 Melakukan pembatalan penulisan data dengan rollback.
