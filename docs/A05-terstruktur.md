# A05 — Pemrograman terstruktur

`util/01_biaya_layanan.php` menggunakan input keyboard, percabangan diskon, dan fungsi. `02_hitung_sla.php` mengubah input menjadi tenggat. `03_csv_ringkasan.php` membaca CSV, mengulang baris, menghitung array, dan menulis file. `04_array_prioritas.php` menyatakan array satu dimensi lima string dan mengurutkannya. `05_menu.php` menjalankan prosedur menu dan fungsi SLA secara bersama. Jalankan `php -l util/*.php` per berkas dan simpan keluaran. Bukti koreksi kesalahan sintaks perlu dibuat dari perubahan nyata; jangan merekayasa error.
