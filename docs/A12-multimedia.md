# A12 — Multimedia

Platform: browser modern dengan JavaScript dan Canvas, layar 360 px–1920 px, Windows/XAMPP/PHP 8.2. Slideshow ada pada `/slideshow` dan `public/assets/js/slideshow.js`. Section: ringkasan layanan. Timeline frame: Total (4,5 dtk), Terbuka (4,5 dtk), Lewat SLA (5 dtk), Grafik status (6 dtk), Petugas teratas (5 dtk). `renderFrame()` mengubah label, nilai/grafik, deskripsi, dan progress bar pada frame yang sama; target path adalah elemen DOM ber-ID `slide-*`. Kontrol play/pause, next/prev, fullscreen tersedia. Transisi nilai memakai opacity dan transform.

Uji kompatibilitas visual Chrome/Firefox/Edge dan perangkat 360 px belum direkam. Jangan klaim elemen kompatibilitas selesai sebelum uji manual tersebut.
