# A04 — Skenario UX dan wireframe

Titik awal hitungan aksi adalah dashboard setelah login. Target: buat tiket ≤4 aksi, ambil tiket ≤3, komentar ≤3, selesaikan/tutup ≤3, ekspor ≤4. Wireframe tekstual: navigasi tetap di atas; dashboard berisi kartu ringkasan dan grafik; daftar tiket berisi filter, tabel, dan tombol tiket baru/ekspor; detail tiket berisi konten dan komentar di kiri, tindakan dan timeline di kanan. Pada layar sempit kolom ditumpuk. Mode gelap tersedia melalui tombol Tema.

Hitungan aksi aktual dan uji pengguna belum dicatat. Skenario membuka kembali tiket hanya tersedia pada status Selesai dan dalam 7 hari. Pemeriksaan izin ada di server, bukan bergantung pada tampilan tombol.
